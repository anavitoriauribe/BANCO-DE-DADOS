# no HTTP:
- GET -> leitura;

- POST -> criação;

- DELETE -> apagar;

- PUT -> atualização;

# no SQL:
- SELECT * FROM tabela; -> leitura da tabela;

- INSERT INTO tabela (nome coluna) VALUES; -> iserir valores;

- DELETE FROM produtos WHERE id = 1; -> apagar;

- UPDATE produtos SET nome = 'Iphone 18' WHERE id = 1; -> atualizar;


OBS: **sempre** usar o WHERE em delete e update para ser especifico onde você quer fazer alterações.
